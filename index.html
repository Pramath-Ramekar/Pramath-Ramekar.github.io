Who is writing this

I came up through bug bounty and traditional penetration testing. 3,000+ hours hunting web, API and infrastructure bugs on HackerOne and Bugcrowd, reaching OWASP Top 10 7/10 and API Top 10 4/10 coverage. Now I've moved that same discipline onto agentic AI.

The shift from breaking websites to breaking agents is where I'm focused now: an agent authentication bypass against production infrastructure, a system prompt leak exposing a full tool schema, and an Adobe Express content filter bypass found at NullCon Goa 2026 and reviewed by Adobe's security team.

Autonomy is something an agent earns through evidence, never something it's granted.

Day job is SOC and internal pentesting at Arica Tech Security LLP, where I deployed the company's Wazuh SIEM from zero.

AI Security Labs

Four labs · attack then harden
01 / ATTACK
Find the break
Jailbreaks, injection and exfiltration against a live baseline.
02 / MEASURE
Prove the control fails
Reproduce the smallest path that shows the limit is real.
03 / HARDEN
Rebuild it
Policy engine, approval gate, 6-layer RAG defence, detection rules.
04 / VERIFY
Re-run and show the delta
Same attack matrix, measured before and after. Numbers, not claims.

Method. Each lab runs my own attack suite against the vulnerable baseline, then the same suite against the hardened build. Pass rates measure the defence, not the attack.
